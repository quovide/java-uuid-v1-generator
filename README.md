# Java UUID v1 Generator
This library provides an implementation strategy for version 1 UUID generator.
This implementation considers a 'node' to be an instance within a Java process.
The node is generated by hashing environment variables together with random data, and using the first 6 bytes, as suggested by the UUID RFC.

```java
UUID id = UUIDv1.next();
```

The system generator is the `ParallelGenerator`. Another `Generator` class (with a public no-arg constructor) can be selected with the system property `eu.msmit.uuid.v1.generator`.

Requires Java 8 or later.

## UUID v7
Version 7 UUIDs (RFC 9562) are ordered by creation time, and do not contain a node.

```java
UUID id = UUIDv7.next();
long createdAt = UUIDv7.timestamp(id);
```

UUIDs are identifiers, not secrets. Do not use them as tokens.
